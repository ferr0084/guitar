This project is an attempt to create the most concise guide to getting started with jazz guitar for someone who already knows some of the basics. These are the essential frameworks that allowed me to connect the dots and understand how it works.

I recommend checking out or downloading this repo and opening it as an Obsidian vault. 

You are going to want to track what you practiced and Obsidian's built in "Daily note" makes it easy. In Obsidian, open this folder as a vault then go to settings -> Core plugins -> Daily notes -> New file location and set it to "journal". Then create a "journal" folder in the vault. Now when you click on the Daily note button, it will create a new note in the journal folder.
